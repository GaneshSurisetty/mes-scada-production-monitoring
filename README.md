# MES/SCADA Production Monitoring & Downtime Analysis

## Project Overview
A simulated manufacturing IT solution for
monitoring production equipment, analyzing
downtime, identifying machine faults, and
calculating operational KPIs using Python,
SQL, and Power BI.

## Objectives
- Monitor equipment status and production events.
- Detect equipment downtime and recurring faults.
- Validate simulated equipment event data.
- Calculate equipment availability and downtime KPIs.
- Visualize production performance using Power BI.

## Technology Stack
- Python — Event generation and validation
- SQL — Data modeling and KPI calculations
- Power BI — Manufacturing analytics
- MES/SCADA Concepts — Production monitoring

## Planned Architecture
Simulated Equipment Events
     ↓
Python Validation
     ↓
SQL Database
     ↓
KPI Analysis
     ↓
Power BI Dashboard

## Project Status
In development.

## Disclaimer
Independently developed simulation using
synthetic manufacturing data. No actual
production PLCs or SCADA servers are connected.
